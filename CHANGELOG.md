# Changelog

## 1.2.0 — Persian Domain Foundation

### Added
- PersianNumberInput
- CurrencyInput
- IranPhoneInput
- NationalIdInput
- JalaliDatePicker
- Persian/Arabic digit normalization utilities
- Toman/Rial formatting and conversion helpers
- Iranian mobile validation
- Iranian national ID validation
- Jalali/Gregorian utility wrappers

### Changed
- Package version moved to 1.2.0.
- Project positioning changed from a generic RTL component collection to a Persian product toolkit.

### Principles
- No copied component implementations.
- No cloned visual identity.
- Domain-specific behavior is explicit and testable.
