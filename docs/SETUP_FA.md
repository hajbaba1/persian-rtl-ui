# راه‌اندازی فارسی

## نیازمندی
Node.js 20.19+ یا 22.12+.

## اجرا
```bash
npm install
npm run dev
```

## کنترل کیفیت
```bash
npm run typecheck
npm run build
```

## قابلیت‌های نسخه 1.2
- تبدیل اعداد فارسی/عربی به لاتین
- نمایش اعداد فارسی
- ورودی تومان و ریال
- تبدیل تومان به ریال و برعکس
- نرمال‌سازی شماره موبایل ایران
- اعتبارسنجی کد ملی
- تقویم جلالی
